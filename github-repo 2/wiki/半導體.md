# 半導體

## 定義
**半導體**是導電性介於導體與絕緣體之間的物質。矽的結構與鑽石相同，但**能隙較小**，所以在常溫下有少數電子能越過能隙，使矽成為半導體元素。

## 重點
- **矽 vs 鑽石**：鑽石的填滿與空軌域間能隙大，電子無法被激發 → 絕緣體；矽能隙較小，25 °C 時就有少數電子能跨越 → 半導體。
- **溫度效應**：溫度升高，有更多能量把電子激發到導帶，矽的導電性**增加**；金屬則相反，導電性隨溫度**降低**。
- **摻雜**：在矽晶體中替換少量其他元素，可在常溫提高導電性。
  - **n 型半導體**：摻入價電子**較多**的原子（如砷，多 1 個價電子）。額外電子的能量接近導帶，容易被激發去導電。
  - **p 型半導體**：摻入價電子**較少**的原子（如硼，只有 3 個價電子）。產生電子空缺（**電洞**）；電子填補電洞後留下新的電洞，電洞反方向移動。從軌域角度：低能量的 MO 原本剛好填滿，硼使其中出現空位，產生單獨的電子可導電。名稱 p 來自可視為電荷載體的**正**電洞。
- 實際應用多連接 p 型與 n 型形成 p–n 接面（課本繼續討論接面電位與順向、逆向偏壓，Wiki 未收錄）。
- 能隙概念與 [[金屬鍵]] 的能帶模型、[[網狀固體]] 的鑽石絕緣體說明是同一套。

## 例題
**題目**（自編）：摻入磷（價電子 5 個）的矽是 n 型還是 p 型？
1. 矽有 4 個價電子，磷多 1 個。
2. 摻入價電子較多的原子 → n 型。

**驗算**：與課本 As（5 個價電子）造成 n 型的描述一致 ✓。（P 的價電子數 5 取自週期表知識，非課本此節原文。）

## 常見誤解
- 「溫度升高，所有導體的導電性都增加」：金屬降低，半導體增加。
- 「p 型是因為多了正電荷」：是缺少電子形成電洞，整體仍是電中性。
- 「n 型有多餘電荷」：多出的是可移動的價電子，晶體仍為電中性。
