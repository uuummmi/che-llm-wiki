# 離子鍵 vs 共價鍵 vs 極性共價鍵

## 定義
三者是同一條光譜上的位置，差別在於共用電子是否均等、電負度差多大，不是三種截然不同的東西。

## 重點
| | 共價鍵（非極性） | 極性共價鍵 | 離子鍵 |
|---|---|---|---|
| 電負度差（表 8.1，定性） | 零 | 中等 | 很大 |
| 電子 | 均等共用 | 不均等共用 | 電子轉移 |
| 例子 | H₂、F₂、Cl₂ | HF、HCl、H₂O | NaCl、CaO（固態） |
| 離子性成分 | 最低 | 中間 | 最高 |

- **離子性百分比**＝（X–Y 的實測偶極矩 ÷ 假設完全離子 X⁺Y⁻ 的計算偶極矩）× 100%。
- **圖 8.13**（氣態二元化合物）：離子性隨電負度差增加，但**沒有任何一個達到 100%**。課本據此說：離散原子對之間大概沒有完全離子性的鍵。離子性大於 50% 的化合物通常被視為離子固體。
- **但這是氣態數據**：固態中許多離子同時作用，離子的存在更有利，所以不能直接套用到固體。
- **多原子離子**：NH₄Cl 含 NH₄⁺ 與 Cl⁻，Na₂SO₄ 含 Na⁺ 與 SO₄²⁻，離子**內部**的鍵是共價鍵。
- **課本的操作型定義**：任何熔融後能導電的化合物，歸類為離子化合物。

## 例題
**題目**（自編，使用圖 8.3 電負度）：判斷下列各鍵的類型：Cl₂、HCl、NaCl(s)，以及 Na₂SO₄ 中的 S–O 鍵。

**解**：
1. Cl₂：差 = 0，**非極性共價鍵**。
2. HCl：3.0 − 2.1 = 0.9，**極性共價鍵**。
3. NaCl(s)：3.0 − 0.9 = 2.1，差很大，熔融能導電，**離子鍵**。
4. Na₂SO₄ 的 S–O：硫酸根內部的鍵是共價鍵，3.5 − 2.5 = 1.0，為**極性共價鍵**；Na⁺ 與 SO₄²⁻ 之間才是離子鍵。

**驗算**：電負度差皆重新計算。

## 常見誤解
- 「離子鍵與共價鍵是兩種完全不同的鍵」：課本把它們放在連續光譜上，並指出氣態中沒有 100% 離子性的鍵。
- 「電負度差大於某個數字（如 1.7）就是離子鍵」：**本課本沒有給數值分界**，表 8.1 只有定性分類。若其他來源有數值，要記為補充或矛盾。
- 「含離子的化合物，裡面所有的鍵都是離子鍵」：多原子離子內部是共價鍵。
