# 電負度

## 定義
電負度是原子在分子中吸引共用電子的能力。

## 重點
- **Pauling 的方法**：假想分子 HX，先算「預期」的 H–X 鍵能：

  預期 H–X 鍵能 = (H–H 鍵能 + X–X 鍵能) / 2

  再比較實測值：Δ = (H–X)實測 − (H–X)預期。
  - 若 H 與 X 電負度相同，Δ = 0。
  - 若 X 電負度較大，鍵多了離子成分的額外吸引，實測鍵能較大，Δ > 0；電負度差愈大，Δ 愈大。
- **範圍**：最大是 F 的 4.0，最小是 Cs 的 0.7（圖中 Fr 也是 0.7）。
- **趨勢**（代表元素）：同週期由左到右增加；同族由上到下減少。
- **常用數值**（圖 8.3，Pauling 值）：

| 元素 | 電負度 | 元素 | 電負度 |
|---|---|---|---|
| H | 2.1 | Si | 1.8 |
| Li | 1.0 | P | 2.1 |
| Na | 0.9 | S | 2.5 |
| Mg | 1.2 | Cl | 3.0 |
| Ca | 1.0 | Br | 2.8 |
| B | 2.0 | I | 2.5 |
| C | 2.5 | N | 3.0 |
| O | 3.5 | F | 4.0 |

- **與鍵型的關係**：差為零是共價鍵，中等是極性共價鍵，很大是離子鍵（表 8.1，定性）。
- **與偶極矩的關係**：HX 的偶極矩隨 X 的電負度下降而下降（見 [[偶極矩]]）。

## 例題
**題目**（自編，使用圖 8.3 的數值）：排序 C–H、N–H、O–H 的極性，並指出各鍵中哪一端帶部分負電。

**解**：
1. C–H：2.5 − 2.1 = 0.4；N–H：3.0 − 2.1 = 0.9；O–H：3.5 − 2.1 = 1.4。
2. 極性：**C–H < N–H < O–H**。
3. 負端：C–H 中是 C；N–H 中是 N；O–H 中是 O（電負度較大者）。

**驗算**：三個差值重算無誤。

## 常見誤解
- 「電負度由上到下增加」：正好相反，同族往下電負度降低。
- 「電負度是原子的絕對屬性」：定義是原子**在分子中**吸引共用電子的能力，Pauling 值是用鍵能比較得出的相對數值。
