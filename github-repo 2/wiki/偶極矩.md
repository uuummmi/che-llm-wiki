# 偶極矩

## 定義
分子若有一個正電荷中心和一個負電荷中心，就稱為具有偶極矩（dipolar）。慣用箭頭表示，箭尾在正端，箭頭指向負端。

## 重點
- **雙原子分子**：只要有極性鍵，就必然有分子偶極矩。
- **HX 的偶極矩**（表 8.2，單位 Debye）：

| 分子 | 鹵素電負度 | 偶極矩 |
|---|---|---|
| HF | 4.0 | 1.86 |
| HCl | 3.0 | 1.05 |
| HBr | 2.8 | 0.82 |
| HI | 2.5 | 0.38 |

  鹵素電負度愈小，偶極矩愈小。
- **多原子分子**：H₂O、NH₃ 有偶極矩；CO₂ 沒有，因為它是線形，兩個 C=O 的極性方向相反而抵消（圖 8.7）。
- **有極性鍵卻沒有偶極矩的三類**（表 8.3）：
  1. 線形、兩個相同的鍵（例：CO₂）
  2. 平面、三個相同的鍵彼此相隔 120°（例：SO₃）
  3. 四面體、四個相同的鍵彼此相隔 109.5°（例：CCl₄）
- **判斷方法**：先看每個鍵的極性方向，再看分子形狀，檢查向量是否抵消 → 需要 [[VSEPR]]。
- **偶極矩的另一個用途**：用實測偶極矩與「完全離子」的計算值相比，可得離子性百分比，見 [[離子鍵vs共價鍵vs極性共價鍵]]。

## 例題
**題目**（課本 Example 8.2）：判斷 HCl、Cl₂、SO₃、CH₄、H₂S 哪些有偶極矩。

**解**：
1. HCl：Cl（3.0）比 H（2.1）電負度大，Cl 帶 δ⁻，**有偶極矩**。
2. Cl₂：兩原子相同，無極性鍵，**無偶極矩**。
3. SO₃：O（3.5）比 S（2.5）電負度大，但分子為平面、三個相同的鍵 120° 對稱，鍵極性抵消，**無偶極矩**。
4. CH₄：四面體、四個相同的 C–H 鍵對稱，**無偶極矩**。
5. H₂S：V 形，S–H 鍵的極性不抵消，**有偶極矩**。

答案：**HCl 與 H₂S 有偶極矩**。

**驗算**：鍵極性抵消與否與課本表 8.3 的三類對照一致。

## 常見誤解
- 「有極性鍵就有偶極矩」：不成立，見 [[極性鍵vs極性分子]]。
- 「偶極箭頭指向正端」：本書的箭頭指向**負端**，箭尾在正端。
