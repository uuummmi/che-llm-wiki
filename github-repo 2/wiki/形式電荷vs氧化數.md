# 形式電荷 vs 氧化數

## 定義
兩者都是給分子中的原子「分配電荷」的簿記方法，差別在於**共用電子怎麼分**。

## 重點
| | 形式電荷 | 氧化數（oxidation state） |
|---|---|---|
| 共用電子 | 平分給兩個原子 | 全部給電負度較大的原子 |
| 主要用途 | 評估路易斯結構是否合理 | 追蹤氧化還原反應中的電子 |
| 與實際電荷 | 只是估計，但比氧化數接近 | 課本說會造成高度誇大的電荷估計 |
| 適不適合評估路易斯結構 | 適合 | 不適合 |

- 氧化數的完整規則見 [[氧化數]]（Ch.4 表 4.2）。
- 課本（§8.12）說明：氧化數的做法是把共用電子全算給電負度大的原子，所以會誇大電荷；氧化數適合用來追蹤氧化還原反應中的電子，但不是原子上實際電荷的真實估計，不適合拿來判斷路易斯結構。
- 形式電荷雖然比氧化數更接近實際電荷，仍然**只是估計**，不應當成真實的原子電荷。

## 例題
**題目**（自編；依課本對氧化數的描述，並使用 §8.12 的 SO₄²⁻ 全單鍵結構）：比較同一個結構中 S 與 O 的形式電荷，以及「共用電子全給電負度大的原子」時的電荷。

**解**：
1. 結構：S 與 4 個 O 各以單鍵相連，每個 O 有 3 個孤對。
2. **形式電荷**（平分共用電子）：O：6 − (6 + 1) = **−1**；S：6 − (0 + 4) = **+2**。
3. **全給電負度大的原子**（O 電負度 3.5 > S 的 2.5）：S 的 8 個共用電子全給 O，S 分配 0 個，電荷 = 6 − 0 = **+6**；每個 O 分配 6 + 2 = 8 個，電荷 = 6 − 8 = **−2**。

**驗算**：形式電荷 +2 + 4(−1) = −2 ✓；氧化數方式 +6 + 4(−2) = −2 ✓；皆等於 SO₄²⁻ 的總電荷。可見第二種估計值大得多（+6 比 +2）。

**用 Ch.4 規則複核**：表 4.2 規則（O 為 −2，離子總電荷為 −2）直接得到 S = +6、O = −2，與第 3 步的結果相同 ✓。

**另一個例子**（自編，H₂O）：氧化數：O = −2、H = +1（共用電子全給 O）。形式電荷：O：6 − (4 + 2) = 0；H：1 − (0 + 1) = 0，所以 H₂O 的形式電荷全是 0，氧化數卻是 −2 與 +1。

## 常見誤解
- 「形式電荷就是氧化數」：兩者分配共用電子的方式不同，數值常不同（如上例）。
- 「氧化數是原子上的真實電荷」：課本說它會高度誇大。

## 矛盾
無。Ch.4 對氧化數的定義（共用電子全給吸引力強的原子）與 Ch.8 的描述一致。
