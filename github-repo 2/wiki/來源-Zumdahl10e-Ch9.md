## 矛盾
無跨來源矛盾。**與 Ch.8 的關係**：Ch.8 §8.9 預告「軌域」是局域電子模型第三部分，Ch.9 §9.1 補上，兩章一致。Ch.8 §8.11 說超過八隅體是否用 d 軌域有爭議，Ch.9 進一步說用 d 軌域的描述「不準確」，語氣更強，但方向一致。**書內小差異**：N≡N 鍵能 Ch.8 表 8.5 是 941、Ch.9 圖 9.38 是 942 kJ/mol；H₂ 的 432 kJ/mol 在 Ch.9 §9.2 與表 8.5 一致（見 [[化學鍵（能量觀點）]] 的 ⚠️）。
