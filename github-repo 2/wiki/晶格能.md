# 晶格能

## 定義
晶格能是氣態離子堆積成離子固體時的能量變化：M⁺(g) + X⁻(g) → MX(s)。本書依「系統觀點」取符號，放熱為負，所以**晶格能是負值**。

## 重點
- **符號慣例（注意）**：課本說晶格能常被描述為離子固體形成時「釋放」的能量，但本書的規則是放熱一律用負號。其他資料可能用正值表示同一個量，閱讀時要先確認定義。
- **LiF 的五步能量**（Li(s) + ½F₂(g) → LiF(s)）：

| 步驟 | 能量 (kJ/mol) |
|---|---|
| Li(s) → Li(g)（昇華） | 161 |
| Li(g) → Li⁺(g) + e⁻（游離能） | 520 |
| ½F₂(g) → F(g)（解離 F–F，154 的一半） | 77 |
| F(g) + e⁻ → F⁻(g)（電子親和力） | −328 |
| Li⁺(g) + F⁻(g) → LiF(s)（晶格能） | −1047 |
| **總和** | **−617** |

- **重點觀察**：F 得電子放出的 328 不夠補償 Li 失電子需要的 520，所以「形成分開的氣態離子」其實是**吸熱**；離子化合物形成的主要驅動力是大量的負晶格能。
- **修正的庫侖定律**：晶格能 = k (Q₁Q₂ / r)。k 是與固體結構及離子電子組態有關的比例常數，Q 是離子電荷，r 是陰陽離子中心的最短距離。電荷愈大、距離愈小，晶格能愈負（愈放熱）。
- **NaF 與 MgO 的對照**（圖 8.11）：

| 項目 (kJ/mol) | NaF | MgO |
|---|---|---|
| 金屬昇華 | 109 | 150 |
| 金屬游離能 | 495 | 2180（735 + 1445） |
| 非金屬解離 | 77 | 247 |
| 電子親和力 | −328 | 737（−141 與 +878） |
| 晶格能 | −923 | −3916 |
| 總能量變化 | −570 | −602 |

  - MgO 的晶格能約為 NaF 的 4.24 倍（−3916 ÷ −923）；Q₁Q₂ 的比值為 (+2)(−2) ÷ (+1)(−1) = 4，兩者接近。
  - MgO 的晶格能比 NaF 負約 3000 kJ/mol，足以補償形成 Mg²⁺ 與 O²⁻ 所需的高能量，所以固體含 Mg²⁺O²⁻ 而不是 Mg⁺O⁻。
  - 為什麼 NaF 不是 Na²⁺F²⁻？從 Na⁺ 再移走一個電子要 4560 kJ/mol（得移走 2p 電子），且 F⁻ 再加一個電子得放進較高能的 3s 軌域，額外能量超過多得的晶格能。
- **結構**：鹼金屬與鹵素形成的二元離子化合物（銫鹽除外）都是 NaCl 結構，每個離子被 6 個相反電荷的離子包圍（圖 8.10）。

## 例題
**題目**（自編，使用課本圖 8.11 的數據）：算 NaF 形成的總能量變化。

**解**：
1. 加總五步：109 + 495 + 77 + (−328) + (−923)
2. 109 + 495 = 604；604 + 77 = 681；681 − 328 = 353；353 − 923 = **−570 kJ/mol**

**驗算**：與圖 8.11 的 −570 一致。MgO 同法：150 + 2180 + 247 + 737 − 3916 = −602 ✓。

## 常見誤解
- 「離子化合物形成是因為電子轉移放熱」：Li(g) + F(g) → Li⁺(g) + F⁻(g) 其實是吸熱（520 − 328 = +192 kJ/mol，依課本數據計算）。
- 「晶格能一定是正數」：本書取負值；定義方向因資料而異。

## 矛盾
無事實矛盾。有**符號慣例不同**與**數值小差異**，見下方跨來源對照。

**跨來源對照（2026-11-23，[[來源-OpenStax-Chem2e-7.5]]）**：
- **符號慣例相反，兩本書都明說**：Zumdahl 定義為 M⁺(g) + X⁻(g) → MX(s)，放熱，**負值**；OpenStax 定義為 MX(s) → M⁺(g) + X⁻(g)，吸熱，**正值**，並註明「有些課本用相反的慣例，定義為釋放的能量」。這是定義方向不同，不是事實矛盾；讀任何資料前先確認它的定義。
- **數值（大小）**：LiF 為 1047（Zumdahl，負）對 1023（OpenStax，正）kJ/mol；MgO 為 3916 對 3900 kJ/mol。差異約 2.3% 與 0.4%，兩本書都沒有說明原因，可能來自不同的資料來源或計算方法，本 Wiki 不推測。
- **趨勢一致**：兩本書都說電荷愈大、離子愈小，晶格能的大小愈大；OpenStax 另指出同時把陽離子與陰離子電荷加倍，晶格能變為 4 倍（與 Zumdahl 的 Q₁Q₂ 比值 4 相符）。
