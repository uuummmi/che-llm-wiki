# 固體的類型

## 定義
固體依結構分為**晶體固體**（成分排列高度規則）與**非晶質固體**（相當無序，如玻璃）。晶體固體再依「晶格點上放的是什麼」分成原子固體、分子固體與離子固體。

## 重點
- **晶格與單位晶胞**：晶格是三維的點陣，標出成分（原子、離子或分子）的位置；能重複形成整個晶格的最小單位叫**單位晶胞**。常見三種立方晶胞：簡單立方、體心立方、面心立方（例：釙、鈾、金）。
- **玻璃**：最好看成「在來得及有序排列前被凍住」的溶液；雖然有剛性，結構中有很大的無序。
- **三大類**（依晶格點上的成分）：
  - **原子固體**：晶格點上是原子，如碳（石墨、鑽石、富勒烯）、硼、矽與所有金屬。
  - **分子固體**：晶格點上是分離的、相對較小的共價分子，如蔗糖、冰（每個晶格點一個 H₂O）。
  - **離子固體**：晶格點上是離子，如 NaCl。
- **原子固體再分三種**（表 10.4）：

| | 金屬固體 | 網狀固體 | 第 8A 族固體 | 分子固體 | 離子固體 |
|---|---|---|---|---|---|
| 晶格點成分 | 金屬原子 | 非金屬原子 | 第 8A 族原子 | 分離的分子 | 離子 |
| 鍵結 | 離域共價 | 方向性共價（形成巨大分子） | 倫敦分散力 | 偶極—偶極力與（或）倫敦分散力 | 離子鍵 |

- **性質差異很大**（課本比較三個原子固體）：
  - Ar（第 8A 族）：熔點很低，**−189 °C**；絕緣體。
  - 鑽石（網狀固體）：熔點約 **3500 °C**；絕緣體；已知最硬的天然物質。
  - 銅（金屬固體）：熔點 **1083 °C**；優良的電導體；可展、可延。
- **鹽與糖**：NaCl 溶於水後離子自由移動，溶液導電；蔗糖溶解後是中性分子，溶液不導電。這說明離子固體與分子固體的差別。
- 金屬見 [[金屬鍵]]；網狀固體見 [[網狀固體]]、[[二氧化矽與矽酸鹽]]、[[半導體]]；分子固體中的力見 [[分子間作用力]]；離子固體見 [[離子鍵]]、[[晶格能]]。

## 例題
**題目**（自編）：把 NaCl、蔗糖、銅、Ar 各歸類，並說出晶格點上的成分。
1. NaCl：離子固體，Na⁺ 與 Cl⁻。
2. 蔗糖：分子固體，分離的蔗糖分子。
3. 銅：原子固體中的金屬固體，銅原子。
4. Ar：原子固體中的第 8A 族固體，Ar 原子（靠倫敦分散力）。

**驗算**：依表 10.4 的成分與鍵結欄位對照 ✓。

## 常見誤解
- 「固體一定有規則結構」：玻璃是固體卻是非晶質。
- 「原子固體的性質都相似」：Ar、鑽石、銅的熔點與導電性天差地別。
- 「分子固體裡有離子」：分子固體晶格點上是分離的中性分子。
