# 極性共價鍵

## 定義
兩個電負度不同的原子共用電子時，電子被拉向電負度較大的原子，使一端帶部分負電（δ⁻）、另一端帶部分正電（δ⁺）的共價鍵。

## 重點
- **HF 的證據**：把 HF 放進電場，分子會傾向排列，F 端朝正極（圖 8.2），說明 F 端帶負電、H 端帶正電。
- **電負度差決定鍵型**（表 8.1，只有定性分類）：差為零是共價鍵（非極性）；差中等是極性共價鍵；差很大是離子鍵。**課本沒有給出分界的數值。**
- **極性隨電負度差增加**：差愈大，鍵的離子性成分愈大。
- **標示方法**：用 δ⁺、δ⁻，或偶極箭頭（箭頭指向負端）；也可用靜電位圖，紅色是電子豐富區，藍色是電子貧乏區。
- 這種鍵同時有離子成分與共價成分，詳見 [[離子鍵vs共價鍵vs極性共價鍵]]。

## 例題
**題目**（課本 Interactive Example 8.1）：依極性由小到大排序 H–H、O–H、Cl–H、S–H、F–H。

**解**：
1. 查電負度（圖 8.3）：H 2.1、O 3.5、Cl 3.0、S 2.5、F 4.0。
2. 電負度差：H–H = 0；S–H = 2.5 − 2.1 = 0.4；Cl–H = 3.0 − 2.1 = 0.9；O–H = 3.5 − 2.1 = 1.4；F–H = 4.0 − 2.1 = 1.9。
3. 答案：**H–H < S–H < Cl–H < O–H < F–H**。

**驗算**：五個差值重新計算皆與課本一致。

## 常見誤解
- 「有極性鍵的分子一定是極性分子」：不一定，對稱時會抵消，見 [[極性鍵vs極性分子]]。
- 「共價鍵與離子鍵之間有一條明確界線」：課本只給定性分類，並指出沒有任何一個氣態原子對的鍵是完全離子性的。
