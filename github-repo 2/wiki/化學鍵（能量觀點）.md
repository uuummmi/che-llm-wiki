# 化學鍵（能量觀點）

## 定義
化學鍵是把原子結合在一起、使它們表現得像單一單位的作用力。從能量角度看，原子靠在一起之後的總能量比分開時低，鍵才會形成。

## 重點
- **形成條件**：系統傾向最低能量。兩個原子結合後能量下降，才有鍵。
- **氫分子的例子**：兩個 H 原子靠近時，同時有「質子與電子互相吸引」（有利）和「質子與質子、電子與電子互相排斥」（不利）。對核間距作圖，能量曲線有一個最低點，那個距離就是 [[鍵長]]。靠得更近，排斥急遽上升。
- **數值（圖 8.1）**：H–H 鍵長 0.074 nm（74 pm），曲線最低點約 −458 kJ/mol。
- **兩種極端**：電子轉移形成 [[離子鍵]]；電子共用形成 [[共價鍵]]；中間是 [[極性共價鍵]]。
- **鍵是模型，不是實體**：把分子相對於分離原子的總穩定能量，平均分配給各個鍵。
  - CH₄ 逐步拆 C–H 所需能量：435、453、425、339 kJ/mol，合計 1652，平均 1652 ÷ 4 = **413 kJ/mol**。
  - 同一種鍵在不同分子中能量不同：C–H 在 HCBr₃ 與 HCCl₃ 為 380，在 HCF₃ 為 430，在 C₂H₆ 為 410 kJ/mol。所以表中的鍵能是**平均值**。
  - 課本提醒：模型是人設計來解釋現象的，會有侷限，需要時要換更精細的模型。

## 例題
**題目**（依課本 §8.7–8.8 的數據改編，自編）：已知 CH₃Cl 分解成 C 原子、3 個 H 原子與 1 個 Cl 原子需要 1578 kJ/mol，且平均 C–H 鍵能為 413 kJ/mol。估計 C–Cl 的鍵能。

**解**：
1. 總能量 = C–Cl 鍵能 + 3 × (C–H 鍵能)
2. 1578 = D(C–Cl) + 3 × 413 = D(C–Cl) + 1239
3. D(C–Cl) = 1578 − 1239 = **339 kJ/mol**

**驗算**：與表 8.5 的 C–Cl = 339 kJ/mol 一致。

## 常見誤解
- 「原子靠越近越穩定」：能量曲線顯示靠太近時排斥會急升，穩定點在鍵長處。
- 「鍵能是一個固定常數」：同一種鍵在不同分子中數值不同，表中數值是平均。

## 矛盾
無（單一來源）。

⚠️ **書內不一致待查**：圖 8.1 的最低能量 −458 kJ/mol，與表 8.5 的 H–H 鍵能 432 kJ/mol 是兩個不同數字，課本在這兩處都沒有說明差異的原因。請勿把兩者當成同一個量；請對照課本或老師講義確認。

**Ch.9 更新**：Zumdahl Ch.9 §9.2（書頁 367）說 H₂「比分開的氫原子低 432 kJ/mol」，與表 8.5 的 432 一致；−458 仍只出現在圖 8.1，且 Ch.9 沒有解釋。同一本書，所以仍不算跨來源確認。
