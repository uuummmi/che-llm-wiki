# 光電子能譜

## 定義
**光電子能譜**（photoelectron spectroscopy, PES）用光把電子打出分子，量測所需能量，藉此得到分子中電子的能階資訊。課本用 N₂ 說明。

## 重點
- 分子的 PES 實際圖譜很複雜，因為電子的游離能會和兩個 N 原子的振動能量耦合。
- N₂ 的結果有三個主要吸收區：**15.6、16.7、18.6 eV**。
- 對應 N₂ 的 MO 圖：
  - 15.6 eV：移除 σ₂ₚ 電子。
  - 16.7 eV：移除 π₂ₚ 電子。
  - 18.6 eV：移除 σ₂ₛ* 電子。
  - σ₂ₛ 電子能量更低，需要超過氦光源能提供的 **21.2 eV**，所以沒有對應的訊號。
- N₂ 共有 5 個填滿的 MO：σ₂ₛ、σ₂ₛ*、兩個 π₂ₚ、σ₂ₚ。
- 圖 9.40 的能量為負值（束縛電子），0 代表電子不再受兩個核影響，是自由電子；圖不是按比例畫。
- PES 是測試鍵結理論的有用工具。

## 例題
**題目**（自編）：N₂ 的 PES 為什麼只出現三個訊號，而不是四個？
1. N₂ 有 4 個不同能量的填滿 MO 能階（σ₂ₛ、σ₂ₛ*、π₂ₚ、σ₂ₚ）。
2. σ₂ₛ 的游離能超過氦光源的 21.2 eV，所以量不到。
3. 因此只有三個訊號：15.6、16.7、18.6 eV。

**驗算**：與課本說明一致 ✓。

## 常見誤解
- 「PES 圖上的每個峰就是一個電子」：π₂ₚ 有兩個簡併軌域，對應同一個能量。
- 「能量為負表示電子不存在」：負值是束縛能。
