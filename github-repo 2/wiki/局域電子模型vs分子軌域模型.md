# 局域電子模型 vs 分子軌域模型

## 定義
比較兩個描述共價鍵的主要模型：局域電子模型（LE，含路易斯結構、VSEPR、混成）與分子軌域模型（MO）。

## 重點
| 項目 | 局域電子模型 | 分子軌域模型 |
|---|---|---|
| 圖像 | 分子是原子共用電子對的集合 | 分子是新的整體，電子在分子軌域中 |
| 電子 | 定域在原子或兩原子之間 | 離域在整個分子 |
| 鍵結軌域 | 原子軌域（常需混成） | 由原子軌域組合出的分子軌域 |
| 共振 | 需另外加上 | 自然包含（離域） |
| 未成對電子（如 NO、O₂ 的順磁性） | 處理不好（O₂ 預測成逆磁性） | 能正確預測 |
| 鍵能資訊 | 沒有直接資訊 | 鍵級可對應鍵強 |
| 優點 | 簡單，可用於非常複雜的分子 | 預測相對鍵強、磁性、鍵極性，描述離域 |
| 缺點 | 電子定域的假設 | 多原子分子很難做定性應用 |

- **結合使用**：對需要共振的分子，σ 鍵用 LE 模型，π 鍵用 MO 模型（見 [[離域π鍵]]）。
- **選哪個**：課本的原則是用「能解釋重要觀察的最簡單模型」，不夠用時再修正或換模型。

## 例題
**題目**（自編）：O₂ 的磁性用哪個模型預測得對？
1. LE 模型：路易斯結構電子全成對 → 預測逆磁性（課本原文）。
2. MO 模型：π₂ₚ* 有 2 個未成對電子 → 順磁性，與液態氧被磁鐵吸引一致。
3. 答案：MO 模型。

**驗算**：與 [[順磁性與逆磁性]] 頁的課本說法一致 ✓。

## 常見誤解
- 「MO 模型取代了 LE 模型」：課本把兩者並用，各取所長。
- 「LE 模型是錯的」：它很有用，只是有已知限制。
