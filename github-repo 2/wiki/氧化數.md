# 氧化數

## 定義
**氧化數**（oxidation state，也稱 oxidation number）是用來追蹤氧化還原反應中電子的簿記方法，特別適用於共價化合物。做法：把共用電子**人為地**指派給原子。相同原子間的共價鍵，電子平分；不同原子間，共用電子**全部**指派給對電子吸引力較強的原子。氧化數就是原子在這種分配下的「想像的電荷」。

## 重點
- **例：H₂O**：O 的吸引力比 H 強，所以假設 O 擁有全部電子，O 多 2 個電子（氧化數 −2），每個 H 沒有電子（氧化數 +1）。
- **離子化合物**：含單原子離子時，氧化數等於離子電荷。
- **表 4.2：指派規則**

| 對象 | 規則 | 例 |
|---|---|---|
| 元素中的原子 | 0 | Na(s)、O₂(g)、O₃(g)、Hg(l) |
| 單原子離子 | 等於離子電荷 | Na⁺、Cl⁻ |
| 氟 | 在化合物中為 −1 | HF、PF₃ |
| 氧 | 通常是 −2；例外：過氧化物（含 O₂²⁻）中是 −1 | H₂O、CO₂ |
| 氫 | 在共價化合物中為 +1 | H₂O、HCl、NH₃ |

- **加總規則**：中性化合物的氧化數總和為 0；離子的氧化數總和等於離子電荷。
- **寫法**：實際電荷寫成 n+ 或 n−（數字在前）；氧化數寫成 +n 或 −n（數字在後）。
- **非整數氧化數**：Fe₃O₄ 中 O 為 −2，3 個 Fe 要共 +8，所以每個 Fe 是 +8/3。這是規則把所有 Fe 視為相同的結果；實際上可看成 4 個 O²⁻、2 個 Fe³⁺ 與 1 個 Fe²⁺（平均 8/3）。非整數氧化數很少見，用法與整數相同。
- **與形式電荷的差別**見 [[形式電荷vs氧化數]]。

## 例題
**例題**（課本 Interactive Example 4.16）：指派 CO₂、SF₆、NO₃⁻ 中各原子的氧化數。
- (a) CO₂：O 為 −2（有專門規則，先指派）；總和為 0，所以 C = **+4**。驗算：1(+4) + 2(−2) = 0。
- (b) SF₆：F 為 −1；6 個 F 共 −6，所以 S = **+6**。驗算：+6 + 6(−1) = 0。
- (c) NO₃⁻：O 為 −2，3 個共 −6；離子總電荷為 −1，所以 N = **+5**。驗算：+5 + 3(−2) = −1。

## 常見誤解
- 「氧化數是原子的真實電荷」：這是一種任意的電子分配方式，Fe₃O₄ 的 +8/3 就是例子。
- 「氧永遠是 −2」：過氧化物是 −1（課本表 4.2）。
- 「氧化數與離子電荷寫法一樣」：寫法的正負號位置不同。
- 「元素的氧化數看它的電負度」：元素態一律是 0。
