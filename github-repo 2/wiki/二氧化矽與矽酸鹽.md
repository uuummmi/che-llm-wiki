# 二氧化矽與矽酸鹽

## 定義
**二氧化矽**（silica，實驗式 SiO₂）是矽與氧的基本化合物，如石英與某些沙。**矽酸鹽**是以相連的 SiO₄ 四面體為基礎的化合物，存在於多數岩石、土壤與黏土中。

## 重點
- **同族元素、性質天差地別**：C 與 Si 同在第 4A 族，但碳化合物常有長的 C–C 鍵（生物），最穩定的矽化合物則是含 Si–O 鍵的鏈（地質）。
- **為什麼 CO₂ 是氣體而 SiO₂ 是固體**：
  - CO₂：每個 C=O 由 C 的 **sp** 與 O 的 σ 鍵，加上 C 的 2p 形成的 **π 鍵**（見 [[σ鍵與π鍵]]、[[混成軌域]]）。分子小、獨立，是氣體。
  - SiO₂：Si 的 3p 軌域**無法與 O 形成強的 π 鍵**，主因是 Si 原子與其軌域較大，與較小的 O 軌域重疊較不有效。所以 Si 不用 π 鍵，而是以**單鍵**連 4 個 O 來滿足八隅體（見 [[八隅體規則與例外]]）。
  - 結果：每個 Si 在 4 個 O 的**四面體**中心，O 與其他 Si 共用；實驗式雖是 SiO₂，結構卻是 SiO₄ 四面體的**網狀**，不是獨立的 SiO₂ 分子，屬網狀固體（見 [[網狀固體]]）。
- **矽酸鹽**：同樣由 SiO₄ 四面體互連。與二氧化矽（O/Si = 2:1）不同，矽酸鹽的 O/Si 比大於 2:1，含矽氧**陰離子**，需要陽離子平衡電荷，所以是含金屬陽離子與多原子矽氧陰離子的鹽類（例：SiO₄⁴⁻、Si₂O₇⁶⁻、Si₃O₉⁶⁻）。
- **玻璃**：二氧化矽加熱超過熔點（約 **1600 °C**）後快速冷卻，得到非晶質固體——玻璃。結構有大量無序，更像非常黏稠的溶液，與結晶的石英相反（見 [[固體的類型]]）。加入不同添加物可改變玻璃性質，例如加入 B₂O₃ 得到硼矽玻璃（膨脹收縮小，用於實驗器材與炊具，品牌如 Pyrex）。

## 例題
**題目**（自編）：為什麼 CO₂ 的分子是「獨立分子」，SiO₂ 卻不是？
1. C 能用 2p 與 O 形成有效的 π 鍵，所以 C=O 雙鍵可成立，分子成為獨立的 O=C=O。
2. Si 的 3p 較大，與 O 的 2p 重疊差，不能形成強 π 鍵，只能靠 4 個單鍵（Si–O）滿足八隅體。
3. 每個 O 再與另一個 Si 相連 → 無限延伸的網狀結構。

**驗算**：與課本「碳與矽形成 π 鍵能力不同，對 CO₂ 與 SiO₂ 的結構與性質有深遠影響」一致 ✓。

## 常見誤解
- 「SiO₂ 是個小分子，像 CO₂」：它是 SiO₄ 四面體的網狀固體，實驗式不等於分子式。
- 「同族元素的化合物性質相同」：C 與 Si 的 π 鍵能力不同。
- 「玻璃是晶體」：玻璃是非晶質。
