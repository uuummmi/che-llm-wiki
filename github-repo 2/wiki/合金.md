# 合金

## 定義
**合金**（alloy）是含有多種元素混合、且具有金屬性質的物質。因為金屬的結構與鍵結特性，其他元素可以相對容易地引入金屬晶體。

## 重點
- **取代型合金**：部分主體金屬原子被**大小相近**的其他金屬原子取代。
  - 黃銅：主體銅的原子中**約三分之一**被鋅取代。
  - 標準純銀（sterling silver）：93% 銀 + 7% 銅。
  - 白鑞（pewter）：85% 錫、7% 銅、6% 鉍、2% 銻。
  - 水管工焊錫：95% 錫 + 5% 銻。
- **間隙型合金**：小原子占據最密堆積金屬結構中的**空隙**。
  - 鋼是最有名的例子：碳原子在鐵晶體的空隙中。
  - 純鐵相對較軟、有延性與可展性（沒有方向性鍵結，球形原子容易相對移動）。
  - 碳形成強的**方向性**鍵，加入後使合金更硬、更強、延性較低。
  - 碳含量決定性質：低碳鋼（< 0.2% C）有延性、可展，用於釘子、纜線、鏈條；中碳鋼（0.2–0.6%）較硬，用於鐵軌與結構梁；高碳鋼（0.6–1.5%）堅韌且硬，用於彈簧、工具與餐具。
- **合金鋼**：除了鐵與碳還含其他元素，可視為混合的間隙（碳）與取代（其他金屬）合金，例如自行車車架用的鋼管（表 10.5）。

## 例題
**題目**（自編）：黃銅與鋼分別是哪一種合金？為什麼？
1. 黃銅：Zn 原子取代部分 Cu 原子，大小相近 → 取代型。
2. 鋼：C 原子（小）進入鐵晶體的空隙 → 間隙型。

**驗算**：與課本的兩個定義一致 ✓。

## 常見誤解
- 「合金是化合物」：課本定義為含混合元素、具金屬性質的物質。
- 「加碳會讓鐵更軟」：碳形成方向性鍵，使鐵更硬、更強、延性較低。
- 「合金鋼就是單一類型」：可視為取代與間隙的混合。
