# σ鍵與π鍵

## 定義
**σ 鍵**（sigma bond）：共用電子對位於兩原子連線上、兩個原子核之間的區域，由兩個「瓣朝向彼此」的軌域形成。**π 鍵**（pi bond）：電子對位於連線的**上方與下方**，由兩個彼此**平行**的 p 軌域形成。

## 重點
- **多重鍵的組成**：
  - 單鍵 = 1 個 σ。
  - 雙鍵 = 1 個 σ + 1 個 π。
  - 參鍵 = 1 個 σ + 2 個 π。
- **σ 鍵由哪些軌域形成**：混成軌域與另一原子的軌域（如 C₂H₄ 中 sp²–sp² 的 C–C σ、sp²–H 1s 的 C–H σ）。
- **π 鍵由哪些軌域形成**：**沒有混成的 p 軌域**。C₂H₄ 每個 C 剩 1 個 p（垂直於 sp² 平面）；sp 混成的 C 剩 2 個 p。
- **實例**：
  - C₂H₄：C=C 是 1σ + 1π；C–H 是 σ。
  - CO₂：每個 C=O 是 1σ（C 的 sp 與 O 的 sp²）+ 1π（平行 2p 重疊）。
  - C₂H₂（乙炔，系統名稱 ethyne）：C≡C 是 1σ（sp–sp）+ 2π；另一個 sp 與 H 形成 σ。
  - N₂：σ 由兩個 sp 重疊，2 個 π 各由一對平行 p 形成；每個 N 的另一個 sp 放孤對。
  - CO：與 N₂ 相同的鍵結圖像。
- 此區分正好說明路易斯結構中「雙鍵」「參鍵」的意義：多出來的鍵是 π 鍵。

## 例題
**例題**（課本 Example 9.2）：描述 N₂ 的鍵結。
1. 路易斯結構中每個 N 有 2 個有效電子對 → 線形 → sp。
2. 每個 N 有 2 個 sp 與 2 個沒混成的 p。
3. sp 用來形成 N–N 的 σ 鍵與放孤對；兩組平行 p 形成兩個 π 鍵。
4. 參鍵 = 1σ（sp–sp）+ 2π（p–p），孤對各在一個 sp 軌域。

**例題 2**（自編）：C₂H₄ 共有幾個 σ 鍵、幾個 π 鍵？
1. 4 個 C–H（σ）＋ 1 個 C–C σ = 5 個 σ。
2. C=C 的第二個鍵 = 1 個 π。
3. 答案：5 個 σ、1 個 π。

**驗算**：路易斯結構共 5 條鍵線（4 條單鍵＋1 條雙鍵 = 6 對共用電子），5σ + 1π = 6 ✓。

## 常見誤解
- 「雙鍵是兩個一樣的鍵」：課本明說雙鍵一定是 1σ + 1π，兩者位置不同。
- 「π 鍵用混成軌域」：π 鍵用的是沒混成的 p 軌域。
- 「σ 鍵只有單鍵才有」：每一條鍵（單、雙、參）都含一個 σ。
