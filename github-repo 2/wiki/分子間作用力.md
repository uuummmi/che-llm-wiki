# 分子間作用力

## 定義
**分子間作用力**（intermolecular forces）是分子**之間**的較弱作用力；相對的，鍵結（共價鍵、離子鍵）是分子**內**（intramolecular）的作用力。物質由固體變液體變氣體時，分子本身不變，改變的是分子之間的力。

## 重點
- **三種主要類型**：偶極—偶極力（含氫鍵，見 [[氫鍵]]）、倫敦分散力（見 [[倫敦分散力]]）、偶極—誘導偶極作用。三者比較見 [[分子間作用力比較]]。
- **數量級對比（水）**：蒸發 1 mol 液態水需要 40.7 kJ，打斷 1 mol 水分子中的 O–H 鍵需要 934 kJ。所以水沸騰時分子保持完整，克服的是分子間作用力，不是共價鍵。
- **偶極—偶極力**：有偶極矩的分子彼此靜電吸引，正端靠近負端。在凝聚態（液體）中，分子排成最佳折衷：多一點 ⊕…⊖ 吸引，少一點 ⊕…⊕ 與 ⊖…⊖ 排斥。
  - 強度大約只有共價鍵或離子鍵的 **1%**，且隨距離增加**快速減弱**；氣態低壓時分子相距遠，這種力相對不重要。
  - 偶極矩的來源見 [[偶極矩]]、[[極性共價鍵]]。
- **偶極—誘導偶極作用**：極性分子的永久偶極可誘導鄰近非極性分子產生偶極。偶極愈大，誘導能力愈強；非極性分子的電子愈多（極化度愈大），愈容易被誘導。
- **用分子層次分辨物理與化學變化**：
  - 若過程克服的是分子間作用力 → 物理變化，如 H₂O(l) → H₂O(g)，分子未變。
  - 若過程斷裂或形成化學鍵（分子內作用力）→ 化學變化，如 CH₄ + 2O₂ → CO₂ + 2H₂O。
  - **灰色地帶**：NaCl(s) 溶於水。寫成 NaCl(s) → NaCl(aq) 像物理變化；但需要打斷離子鍵，並形成離子與水的作用力，這些力的強度可與共價鍵相當，所以也可論證為化學變化。課本提醒不要過度簡化。
- **凝聚態**：液體與固體。這些作用力使構成粒子聚集。

## 例題
**題目**（自編）：下列過程克服的是分子間作用力還是化學鍵？(a) 冰融化；(b) 水電解成 H₂ 與 O₂。
1. 冰融化：H₂O 分子保持完整，克服的是分子間作用力（氫鍵）→ 物理變化。
2. 水電解：O–H 鍵斷裂、新鍵形成 → 化學變化。

**驗算**：依課本判準（是否破壞或形成化學鍵）✓。能量尺度也一致：水蒸發 40.7 kJ/mol，遠小於 O–H 鍵 934 kJ/mol。

## 常見誤解
- 「水沸騰是 O–H 鍵斷了」：沸騰時分子不變；40.7 kJ 與 934 kJ 相差很大。
- 「偶極—偶極力很強」：只有鍵結的約 1%，而且會隨距離快速減弱。
- 「溶解一定是物理變化」：離子固體溶解屬灰色地帶。
