為什麼要學鍵結　2/31

同樣是碳，為什麼鑽石和石墨差這麼多？

鑽石石墨
硬度最硬滑
顏色基本上無色黑
導電絕緣體導體
混成sp³sp²
密度3.5 g/cm³2.2 g/cm³

兩者都只由碳組成，差別全在鍵結方式。這整份簡報要學的，就是怎麼看懂這種差別。

  • 鑽石：每個 C 連 4 個 C，各方向的鍵一樣強，所以最硬。
  • 石墨：每層內每個 C 連 3 個 C（120°），剩 1 個 p 軌域組成離域的 π 系統，所以能導電。
  • 層與層之間幾乎沒有鍵結，所以層能滑動。
  • 高壓高溫（150,000 atm、2800 °C）可把石墨轉成鑽石。

① 為什麼會有鍵　4/31

化學鍵是什麼？能量降低才會形成

  • 兩個 H 原子靠近時，有有利的「質子—電子吸引」，也有不利的「質子—質子、電子—電子排斥」。
  • 能量曲線有一個最低點，那個距離就是鍵長：H–H 為 0.074 nm（74 pm）。
  • 靠得太近，排斥讓能量急遽上升。
  • 鍵是模型，不是實體：把分子比分開的原子低的能量，平均分配給各個鍵。

⚠️ 待查：課本另一處（表 8.5）的 H–H 鍵能是 432 kJ/mol，與這裡的 −458 不同，課本沒有說明原因，所以本簡報不把兩者混為一談。第 9 章（分子軌域）也說 H₂ 比分開的原子低 432 kJ/mol，仍同一本書，不算跨來源確認。

② 電負度　6/31

電負度：誰比較會搶電子

定義：原子在分子中吸引共用電子的能力。

  • 同一週期：由左到右增加。
  • 同一族：由上到下減少。
  • 範圍：F 最大（4.0），Cs 最小（0.7）。

Pauling 的做法：比較 H–X 的實測鍵能與用 H–H、X–X 平均得到的預期鍵能，差愈大，電負度差愈大。

③ 鍵極性　7/31

鍵的極性：看電負度差

例題：依極性由小到大排序 H–H、S–H、Cl–H、O–H、F–H。

  1. 查電負度，H 是 2.1。
  2. 算差：0、0.4、0.9、1.4、1.9。
  3. 差愈大，愈極性。

答案：H–H < S–H < Cl–H < O–H < F–H

H–H0非極性
S–H0.4
Cl–H0.9
O–H1.4
F–H1.9最極性

電負度差（相對於 H = 2.1）

極性的標記：電負度大的一端帶 δ⁻，小的一端帶 δ⁺。HF 的偶極矩 1.86 Debye，是 HX 中最大的。

① → 離子鍵　8/31

離子鍵：電子轉移，靠庫侖吸引

  • 電子由金屬轉移給非金屬，形成陽離子與陰離子，靠靜電吸引結合。
  • 一對離子的能量（庫侖定律）：

E = (2.31 × 10⁻¹⁹ J·nm) × (Q₁Q₂ / r)

r 是離子中心距離，單位是 nm；Q 是電荷的數值（如 +1、−1）。

例：NaCl 一對離子

r = 0.276 nm，電荷 +1 與 −1

E = (2.31 × 10⁻¹⁹)(+1)(−1) ÷ 0.276
= −8.37 × 10⁻¹⁹ J

負號 = 吸引：離子對比分開的離子能量低。同號離子相斥，E 為正。

共價鍵：鍵愈多愈短愈強，鍵能可以估反應熱

鍵鍵長 pm鍵能 kJ/mol
C–C　單鍵154347

共用的電子對愈多：鍵愈短、愈強。（但雙鍵不是單鍵的兩倍：614 ÷ 347 ≈ 1.77）

用鍵能估算反應熱

ΔH = Σ 斷鍵 − Σ 成鍵

D 永遠是正值；斷鍵吸熱，成鍵放熱，所以成鍵那項要減去。

H₂ + F₂ → 2HF
ΔH = 432 + 154 − 2(565) = −544 kJ
用生成焓算：2 × (−271) = −542 kJ，很接近。

鍵能是平均值，所以只能估算。

④ 路易斯結構　12/31

路易斯結構：價電子怎麼分配

  1. 加總所有原子的價電子（負電荷多一個，正電荷少一個）。
  2. 每對相鄰原子之間用一對電子連成鍵。
  3. 把剩下的電子分配出去，讓 H 有 2 個、C N O F 有 8 個。
  4. 檢查：電子總數對不對？每個原子是否符合規則？

只畫價電子；核心電子不畫。

例：CO₂
  1. 4 + 6 + 6 = 16 個電子
  2. O–C–O 用掉 4 個，剩 12 個
  3. 每個 O 放 3 對孤對 → C 只有 4 個電子 ✗
  4. 改成兩個雙鍵 → 每個原子都是 8 個 ✓

O=C=O　（鍵 4 對 + 孤對 4 對）× 2 = 16

⑤ 共振　14/31

共振：不是來回翻轉，而是平均

  • NO₃⁻（24 個價電子）畫出來是「一個雙鍵、兩個單鍵」，應該有兩種 N–O 鍵長。
  • 但實驗只量到一種 N–O 鍵，長度介於單鍵與雙鍵之間。
  • 雙鍵放在哪個 O 都合理，共 3 個結構。實際結構是三者的平均。

[O=N(–O)–O]⁻ ↔ … ↔ …

  • 所有共振結構中，原子核的位置相同，只有電子的位置不同。
  • 雙箭頭不是分子在結構之間「翻轉」。
  • 共振是為了補償「電子定域」這個假設的缺陷：電子其實是離域的。

⑥ 孤對電子　17/31

孤對電子要比較多空間

三個分子的中心原子都有 4 對電子，但孤對數不同：

CH₄（0 對孤對）109.5°
NH₃（1 對孤對）107°
H₂O（2 對孤對）104.5°

孤對電子只被一個原子核約束，電子會佔據較多空間，把鍵結對擠得更近，鍵角就變小。

模型的侷限

⑧ 軌域：分子軌域　22/31

分子之間的力

  • 水沸騰克服的是分子間作用力：蒸發 1 mol 水只要 40.7 kJ，打斷 1 mol 水的 O–H 鍵要 934 kJ。

  • 倫敦分散力：所有分子都有；電子愈多（極化度愈大）愈強。

⑨ 金屬　26/31

金屬鍵：電子海與能帶

  • 金屬鍵是強、無方向性的離域鍵：難把原子分開，但容易移動它們，所以金屬可展、可延。
  • 電子海模型：規則排列的金屬陽離子，浸在可移動的價電子「海」中。
  • 能帶模型：2 個原子軌域只得 2 個分子軌域；6.02 × 10²³ 個原子軌域則形成幾乎連續的能帶，只被部分填滿，電子容易移動，所以導電、導熱。
導電性隨溫度
金屬：溫度升高，導電性降低。
矽（半導體）：溫度升高，導電性增加。

鑽石的能隙很大，電子過不去，所以是絕緣體；矽的能隙小，常溫就有少數電子能過去。

⑨ 網狀固體　27/31

CO₂ 是氣體，SiO₂ 卻是石頭

CO₂

C 用 sp 與 2p：每個 C=O 是 1σ + 1π → 獨立的 O=C=O 分子 → 氣體

SiO₂

Si 的 3p 太大，與 O 的 2p 重疊差，形成不了強 π 鍵 → 改用 4 個 Si–O 單鍵，每個 Si 在 SiO₄ 四面體中心，O 被相鄰 Si 共用 → 網狀固體（石英）

  • SiO₂ 只是實驗式，不是分子式。O/Si 比 2:1。
  • 加熱超過約 1600 °C 後快速冷卻，得到非晶質的玻璃。

複習　29/31

六個最常見的誤解

  1. 有極性鍵，分子就是極性的。
    → 對稱時會抵消（CO₂、CCl₄）。
  2. NH₃、H₂O 是四面體分子。
    → 只有電子對排列是四面體；形狀是三角錐與 V 形。
  3. 形式電荷就是氧化數。
    → 前者共用電子平分，後者全給電負度大的原子。
  4. 離子鍵和共價鍵是兩種完全不同的鍵。
    → 是一條光譜，氣態下沒有 100% 離子性的鍵。
  5. 電負度由上到下增加。
    → 同族往下降低，同週期往右增加。
  6. 離子化合物形成，是因為電子轉移會放熱。
    → 轉移本身吸熱；真正的驅動力是晶格能。
