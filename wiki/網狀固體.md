# 網狀固體

## 定義
**網狀固體**是原子之間以強的**方向性共價鍵**連成的固體，可看成一個「巨大分子」。與金屬相比，網狀固體通常**脆**，不能有效導熱或導電。課本以碳的兩種形式——鑽石與石墨——為代表。

## 重點
- **鑽石**：每個 C 被 4 個 C 以四面體排列包圍，形成巨大分子。局域電子模型：由 **sp³** 混成軌域重疊形成共價鍵（見 [[混成軌域]]）。
  - 分子軌域觀點：鑽石在填滿與空軌域之間有**很大的能隙**，電子不易被激發到空的導帶，所以預測是**電絕緣體**，與觀察一致（對比金屬，見 [[金屬鍵]]）。
  - 鑽石是已知最硬的天然物質；各方向的鍵結一樣，所以用於工業切削。
- **石墨**：由融合的六元環 C 原子層組成。每個 C 與同層 3 個 C 以三角平面、**120°** 鍵角結合：**sp²** 混成，3 個 sp² 形成 σ 鍵；每個 C 剩下 1 個垂直於平面的未混成 2p 軌域（見 [[σ鍵與π鍵]]）。
  - 這些 p 軌域組成密集的 **π 分子軌域**：(1) 形成 π 鍵，使各層更穩定；(2) 離域電子使石墨**導電**，類似金屬的導帶（見 [[離域π鍵]]）。
  - 層內鍵結很強，**層與層之間幾乎沒有鍵結**（價電子都用在層內的 σ、π 鍵），所以層可以滑動，石墨**滑**，可作鎖的潤滑劑（油會沾灰塵）。
- **鑽石 vs 石墨**：

| | 鑽石 | 石墨 |
|---|---|---|
| 硬度 | 最硬 | 滑 |
| 顏色 | 基本上無色 | 黑 |
| 導電 | 絕緣體 | 導體 |
| 混成 | sp³ | sp² |
| 密度 | 3.5 g/cm³ | 2.2 g/cm³ |

- **石墨轉鑽石**：鑽石密度較高，所以可加高壓轉換；150,000 atm、2800 °C 可使石墨幾乎完全轉成鑽石。高溫是為了斷開石墨中的強鍵使原子重排。
- **石墨烯**（課本的 Chemical Connections）：石墨的單層。課本稱它被認為是已知最強的材料，是已知最好的熱與電導體，但大片製造困難。僅屬於延伸閱讀，Wiki 未展開。
- 同樣是原子固體，鑽石與銅、Ar 的性質迥異，見 [[固體的類型]]。

## 例題
**題目**（自編）：鑽石與石墨都只由碳組成，為什麼一個是絕緣體、一個能導電？
1. 鑽石：sp³、每個 C 用 4 個 σ 鍵，沒有離域電子；MO 圖有大能隙。
2. 石墨：sp²、每個 C 有 1 個未混成 p，形成離域 π 系統，像導帶。
3. 結論：差別在於**鍵結（是否有離域 π 電子）**，不是元素。

**驗算**：與課本「這些差異來自兩種固體鍵結的差異」一致 ✓。

## 常見誤解
- 「同一種元素的固體性質一樣」：鑽石與石墨相差極大。
- 「石墨很軟所以鍵很弱」：層內的鍵很強；弱的是層間。
- 「石墨導電是因為是金屬」：是離域 π 電子，類比導帶。
