# 氧化還原反應

## 定義
**氧化還原反應**（redox reaction）是有電子轉移的反應。**氧化**是氧化數**增加**（失去電子）；**還原**是氧化數**減少**（得到電子）。

## 重點
- **直接轉移的例子**：2Na(s) + Cl₂(g) → 2NaCl(s)。氧化數：Na 0 → +1，Cl 0 → −1。Na 被氧化、Cl 被還原。
- **看不出離子的例子**：CH₄ + 2O₂ → CO₂ + 2H₂O。沒有離子化合物，但仍可用氧化數描述為電子轉移：
  - C：−4 → +4，失去 8 個電子（被氧化）。
  - 每個 O：0 → −2，4 個 O 共得到 8 個電子（被還原）。
  - H 的氧化數不變（+1），不參與電子轉移。
- **氧化劑與還原劑**：氧化劑（接受電子）被還原；還原劑（提供電子）被氧化。指名時要寫**整個化合物**，不是只寫改變氧化數的元素。例：CH₄ 是還原劑，O₂ 是氧化劑；Na 是還原劑，Cl₂ 是氧化劑。
- **記憶法**：OIL RIG（氧化是失去，還原是得到）；LEO says GER（Loss of Electrons, Oxidation; Gain of Electrons, Reduction）。
- **重要性**：光合作用、人體對糖、脂肪、蛋白質的氧化、燃燒反應，都是氧化還原反應。

## 例題
**例題**（課本 Interactive Example 4.17）：方鉛礦（PbS）的冶煉：(1) 2PbS + 3O₂ → 2PbO + 2SO₂；(2) PbO + CO → Pb + CO₂。找出被氧化、被還原的原子與氧化劑、還原劑。
1. 反應 (1)：S 由 −2 → +4（被氧化）；O 由 0 → −2（被還原）。氧化劑 O₂，還原劑 PbS。
2. 反應 (2)：Pb 由 +2 → 0（被還原）；C 由 +2 → +4（被氧化）。氧化劑 PbO，還原劑 CO。

**驗算**：氧化劑的元素都被還原、還原劑的元素都被氧化，與定義一致 ✓。

## 常見誤解
- 「氧化就是與氧反應」：課本的定義是氧化數增加。
- 「氧化劑被氧化」：氧化劑**被還原**；還原劑**被氧化**。
- 「沒有離子就沒有電子轉移」：CH₄ 的燃燒是形式上的電子轉移。
